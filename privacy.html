PwP-Jarvis privacy policy

Last updated: 23 September 2026

Who uses it. PwP-Jarvis is a personal application used only by its owner, Phil Panas. It is not offered to anyone else.

What it accesses. With the owner's consent, it accesses the owner's own Google data (Gmail, Calendar, Tasks, Contacts and Drive) through Google's APIs, only to carry out the owner's requests.

Where data goes. The application runs on the owner's own computer. Google user data is processed locally, is not sent to any other server or third party, is not sold, and is not used for advertising.

Storage. Sign-in tokens and any working copies are kept only on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
